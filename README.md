# Система автоматизации выставления оценок (de_grades)

Данный проект представляет собой веб-приложение для автоматизации процесса выставления и просмотра оценок обучающихся по дисциплинам. Разработано в рамках демонстрационного экзамена (ДЭ) по специальности **09.02.07 «Информационные системы и программирование»**.

## 📋 Функциональные возможности

### Роль «Преподаватель»
* Вывод списка дисциплин, которые ведет авторизованный преподаватель.
* Выставление, изменение и удаление оценок выбранному студенту.
* Просмотр всех оценок выбранного студента.
* Просмотр оценок всех студентов выбранной группы.
* **Восстановление удаленных записей.** При удалении оценка не теряется навсегда, а перемещается в «Корзину», откуда её можно восстановить.

### Роль «Студент»
* Авторизация в системе.
* Просмотр только своих оценок по дисциплинам.

### Интерактивный дашборд
* Построение графиков успеваемости (библиотека Chart.js).
* Столбчатая диаграмма среднего балла по дисциплинам.
* Круговая диаграмма распределения оценок.
* **Кросс-фильтрация:** при выборе конкретной дисциплины в выпадающем списке график распределения оценок автоматически перестраивается.

## 🛠️ Технологический стек
* **Язык программирования:** PHP 8.x
* **База данных:** MySQL / MariaDB
* **Веб-сервер:** Apache (XAMPP)
* **Frontend:** HTML5, CSS3, JavaScript (Chart.js)
