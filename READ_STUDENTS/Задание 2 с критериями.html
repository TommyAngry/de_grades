1. Аннотация

💡 Как получить баллы (22 балла за документацию): Эксперт проверяет наличие вводной части (стр. 31). Напишите кратко, для чего нужна система.

Настоящее руководство пользователя предназначено для описания работы с подсистемой автоматизации выставления оценок обучающимся. Система позволяет преподавателям вести учет успеваемости студентов, а студентам — просматривать свои результаты. В системе реализован интерактивный дашборд для визуализации успеваемости, а также механизм мягкого удаления данных (Корзина) для предотвращения потери информации.

2. Назначение и условия применения

Подсистема предназначена для использования в образовательных организациях. Условия применения: персональный компьютер или ноутбук с доступом в сеть, установленный веб-браузер (Google Chrome, Яндекс.Браузер, Firefox), локальный веб-сервер XAMPP (Apache + MySQL/MariaDB + PHP).

3. Функциональные и технические требования

  • Серверная часть: Apache, PHP 8.x, MySQL/MariaDB.
  • Клиентская часть: HTML5, CSS3, JavaScript (библиотека Chart.js).
  • Роли пользователей: Преподаватель, Студент.

4. Описание функций системы

  • Авторизация: Вход в систему по логину и паролю с разделением прав доступа.
  • Роль «Преподаватель»: Просмотр своих дисциплин, выставление/изменение оценок, мягкое удаление оценок, просмотр оценок конкретного студента или всей группы, восстановление оценок из корзины.
  • Роль «Студент»: Просмотр только своих оценок по дисциплинам.
  • Дашборд: Визуализация среднего балла по дисциплинам и распределения оценок с возможностью интерактивной фильтрации.

5. Описание операций

💡 Как получить баллы: КИМ (стр. 31) требует пошагового описания (нумерованные списки) и скриншотов для каждой операции. Не пропускайте ни одну функцию!

5.1. Авторизация в системе

  1. Откройте веб-браузер и перейдите по адресу проекта (например, http://localhost/de_grades/login.php).
  2. Введите логин и пароль, выданные администратором.
  3. Нажмите кнопку «Войти».
[ВСТАВИТЬ СКРИНШОТ: Окно авторизации]

5.2. Работа с системой в роли Студента

  1. После ввода корректных данных студент попадает в личный кабинет.
  2. На экране отображается таблица со списком дисциплин, ФИО преподавателя и полученной оценкой.
  3. Данные доступны только для чтения, изменить их студент не может.
[ВСТАВИТЬ СКРИНШОТ: Кабинет студента с таблицей оценок]

5.3. Работа с системой в роли Преподавателя

5.3.1. Просмотр закрепленных дисциплин

При авторизации преподаватель видит список дисциплин, которые он ведет (согласно расписанию в БД).

[ВСТАВИТЬ СКРИНШОТ: Блок "Мои дисциплины"]

5.3.2. Выставление новой оценки

  1. В блоке «Выставить / изменить / удалить оценку» выберите дисциплину из выпадающего списка.
  2. Выберите учебную группу и конкретного студента.
  3. В поле «Оценка» введите целое число от 2 до 5.
  4. Нажмите кнопку «Сохранить». Оценка мгновенно появится в кабинете студента.
[ВСТАВИТЬ СКРИНШОТ: Заполненная форма выставления оценки]

5.3.3. Изменение существующей оценки

Для изменения выберите ту же дисциплину, группу и студента, введите новое значение в поле «Оценка» и нажмите «Сохранить». Предыдущее значение перезапишется.

5.3.4. Мягкое удаление оценки

  1. Выберите дисциплину и студента.
  2. Оставьте поле «Оценка» абсолютно пустым.
  3. Нажмите «Сохранить». Оценка пропадет из журнала, но физически не удалится из БД.

5.3.5. Восстановление оценки из Корзины

  1. Прокрутите страницу вниз до блока «Удаленные оценки (Корзина)».
  2. Найдите нужную запись в таблице.
  3. Нажмите кнопку «Восстановить». Оценка снова станет активной и вернется студенту.
[ВСТАВИТЬ СКРИНШОТ: Блок Корзины с удаленными оценками и кнопкой "Восстановить"]

5.3.6. Просмотр оценок студента и группы

В блоке «Просмотр оценок» преподаватель может выбрать конкретного студента и нажать «Показать оценки студента», либо выбрать группу и нажать «Показать оценки группы» для формирования сводной ведомости.

[ВСТАВИТЬ СКРИНШОТ: Сформированная ведомость группы]

5.4. Инструкция по работе с Дашбордом

💡 Как получить 3 балла: В КИМ (стр. 32) сказано: "добавить в руководство пользователя инструкцию по работе с дашбордом... при выборе любого показателя изменялись бы другие". Обязательно покажите на скриншотах, как работает фильтр!
  1. Для перехода к аналитике нажмите на ссылку «Дашборд» в верхнем меню.
  2. На экране отображаются два интерактивных графика: столбчатая диаграмма (средний балл по дисциплинам) и круговая диаграмма (распределение оценок 2-5).
  3. В верхней части экрана расположен фильтр «Выберите дисциплину».
  4. При выборе конкретной дисциплины в выпадающем списке, круговая диаграмма автоматически перестраивается и показывает успеваемость только по этому предмету. Столбчатая диаграмма остается общей для сравнения.
[ВСТАВИТЬ СКРИНШОТ: Дашборд без выбранного фильтра (видны все дисциплины)]

[ВСТАВИТЬ СКРИНШОТ: Дашборд с выбранной дисциплиной в фильтре (круговая диаграмма изменилась)]

6. Заключение

Разработанная подсистема полностью соответствует требованиям технического задания. Обеспечивает надежное хранение данных благодаря использованию реляционной СУБД, внешних ключей и механизмов мягкого удаления. Предоставляет удобный инструмент аналитики в виде интерактивного дашборда.
